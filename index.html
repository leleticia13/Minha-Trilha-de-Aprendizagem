Comandos Git

  • git init – inicia um repositório
  • git status – mostra o estado dos arquivos
  • git add . – adiciona alterações à área de preparação
  • git commit -m "mensagem" – salva uma versão
  • git log --oneline – lista o histórico de commits
  • git branch – lista ou cria branches
  • git switch nome – troca de branch
  • git push – envia commits ao repositório remoto
  • git pull – baixa atualizações do remoto
